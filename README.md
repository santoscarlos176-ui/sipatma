# SIPATMA 2026 · Fora da Linha de Fogo

Página da SIPATMA 2026 da Reckitt Raposo Tavares.

- Site publicado: https://sipatma-reckitt-2026.netlify.app
- Contador de acessos: https://sipatma2026.goatcounter.com

## Como atualizar o site
1. Neste repositório, toque em **Add file → Upload files**.
2. Envie o novo arquivo com o nome exato `index.html` (tudo minúsculo). Ele substitui o anterior.
3. Toque em **Commit changes**.
4. O Netlify publica sozinho em cerca de 1 minuto. O link e o QR Code não mudam.
